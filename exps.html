Setup设置

We write the weights of an ordinary transformer of the GPT-2 family (softmax attention, LayerNorm, tanh-GELU MLPs, learned positions) with a program, not by training. Its prompt is another language model: every row of every weight matrix of the inner model is one position, followed by the tokens of a text. Its output at each token should be the inner model's next token. The program reads only the inner model's shape, so the same outer weights run any model of that shape, and a padded version runs any smaller one. Everything runs in float64 on NVIDIA B200 cards, and every result is compared with the inner model run directly in float64.

我们用程序（而不是训练）写出一个 GPT-2 家族的普通 transformer 的权重（softmax 注意力、LayerNorm、tanh 版 GELU 的 MLP、学习的位置嵌入）。它的 prompt 是另一个语言模型：内层模型每个权重矩阵的每一行占一个位置，后面跟着一段文本的 token。它在每个 token 上的输出应当是内层模型的下一个 token。程序只读取内层模型的形状，所以同一套外层权重能运行任何这种形状的模型，补零之后能运行任何更小的模型。所有计算都在 NVIDIA B200 上以 float64 进行，每个结果都和内层模型在 float64 下直接运行的结果比较。

How we test怎么测

  1. The reference is the inner model in float64: Hugging Face transformers for GPT-2; for the Llama family our own float64 forward pass, checked against transformers (agreeing to 3×10−13, with transformers' RMSNorm kept in float64 instead of its usual float32).参考是内层模型的 float64 运行：GPT-2 用 Hugging Face transformers；Llama 家族用我们自己的 float64 前向，并与 transformers 核对（相差 3×10−13；transformers 的 RMSNorm 改为 float64，它默认用 float32）。
  2. At every position of the text we compare the next token, and the logits computed from the inner residual stream that the outer network carries, over the whole vocabulary. We report the largest absolute logit error.在文本的每个位置比较下一个 token，以及从外层携带的内层残差算出的 logits（整个词表）。报告 logits 的最大绝对误差。
  3. The loader scales every matrix row by its largest value on other text (the end of the document, or four TinyStories stories), never on the test text.加载器按每个矩阵行在别的文本（文档末尾，或四段 TinyStories 故事）上的最大值给它定尺度，从不使用测试文本。
  4. When the prompt is cached, the full update of 256 random prompt positions is still computed in every sublayer and must be exactly zero.缓存 prompt 时，每个子层仍然完整计算 256 个随机 prompt 位置的更新，它们必须恰好为零。
  5. Ordinary float32 inference of the same model, against the same reference, is the yardstick.同一个模型的普通 float32 推理相对同一参考的误差，作为标尺。
  6. When a number is worse than expected, we compare the outer network's intermediate values with the inner model's, layer by layer, until the step that loses precision is found.数字比预期差时，逐层比较外层网络的中间值和内层模型的值，直到找到丢精度的那一步。

Experiments实验

Question 1问题 1

Answered已回答Can a transformer with fixed weights run another transformer that it only sees in its prompt?一个权重固定的 transformer，能运行一个只出现在它 prompt 里的 transformer 吗？

A matrix product is the part that needs a construction, because the matrix is in the prompt, not in the outer weights. Pairs of heads attend to the rows of the matrix with queries ±εu; to first order, row j receives weight (1 ± ε⟨wj, u⟩)/N, its value writes that weight to coordinate j, and an anchor row removes the 1/N. With one pair the error falls as ε2 until rounding takes over; two and three pairs (±2ε, ±3ε) cancel more terms. On random two-layer inner models, three pairs reach 3×10−12.

矩阵乘法是需要专门构造的部分，因为矩阵在 prompt 里，不在外层权重里。成对的头以 ±εu 为 query 注意矩阵的各行；一阶近似下第 j 行得到权重 (1 ± ε⟨wj, u⟩)/N，它的 value 把这个权重写到第 j 个坐标，一个锚点行去掉 1/N。只用一对头时误差按 ε2 下降，直到舍入误差占主导；两对、三对（±2ε、±3ε）能消去更多项。在随机的两层内层模型上，三对头达到 3×10−12。

Question 2问题 2

Answered已回答Does it work on a real pretrained model?在真实的预训练模型上行得通吗？

Yes. GPT-2 (124M) as the prompt: 184,531 positions, an outer network of 74 layers and width 11,799. All 1,024 next tokens of the text match, and the logits are within 1.5×10-9 of float64 (float32 inference: 1.4×10-3). The first construction, without per-row scales, also matched every token, at 4.0×10-8.

可以。以 GPT-2（1.24 亿参数）为 prompt：184,531 个位置，外层 74 层、宽 11,799。文本的 1,024 个下一个 token 全部一致，logits 与 float64 相差 1.5×10-9（float32 推理：1.4×10-3）。没有按行定尺度的第一版构造也是全部一致，误差 4.0×10-8。

Question 3问题 3

Answered已回答Is the outer network independent of the inner weights, or did it only work for GPT-2?外层网络真的与内层权重无关吗，还是只对 GPT-2 有效？

The outer weights depend only on the shape, so any checkpoint of GPT-2's shape should run on the weights written for GPT-2. The first construction passed GPT-2 and DistilGPT-2 and failed DialoGPT-small: 964 of 1,024 tokens. DialoGPT's residual stream is five times larger (norm 4,837 against 999), which pushed the linearized products out of their range. The second construction gives every matrix row its own scale, carried in the prompt; it runs all three exactly.

外层权重只取决于形状，所以任何 GPT-2 形状的检查点都应该能在为 GPT-2 写的权重上运行。第一版构造通过了 GPT-2 和 DistilGPT-2，但在 DialoGPT-small 上失败：1,024 个 token 中只有 964 个一致。DialoGPT 的残差大了五倍（范数 4,837 对 999），把线性化的乘积推出了它的有效范围。第二版构造给每个矩阵行一个自己的尺度，放在 prompt 里；三个模型都精确运行。

Question 4问题 4

Answered已回答Can the outer network itself be the prompt of another outer network?外层网络本身能成为另一个外层网络的 prompt 吗？

Yes, after three fixes. The outer network is a GPT-2-family transformer, so it can be the inner model of a second outer network written for its shape. A character model M0 runs inside U1, and U1 runs inside U2. What made it work: every vector the network writes sums to zero (so its LayerNorm is an RMSNorm one level up); masks are built from flags that are exactly zero where they select, with power-of-two weights; and the offset of an embedding lookup is added to the score of the null position instead of sharing a weight row with a mask of 1024, where it vanished in the sum. That last bug broke the 4-layer TinyStories tower (6 of 128 characters) until it was moved.

可以，修了三处之后。外层网络是 GPT-2 家族的 transformer，所以它能成为第二个外层网络的内层模型，后者按它的形状来写。字符模型 M0 在 U1 里运行，U1 在 U2 里运行。让它成立的三处：网络写入的每个向量之和为零（于是它的 LayerNorm 在上一层看来是 RMSNorm）；mask 由在被选中处恰好为零的标记构成，权重都是 2 的幂；嵌入查表的偏移量加在空位置的分数上，而不是和一个 1024 的 mask 共用一行权重（在那里它在求和中消失了）。最后这个 bug 让 4 层的 TinyStories 套娃失败（128 个字符只对 6 个），挪开之后才通过。

Question 5问题 5

Answered已回答How large can the inner model be, and is caching the prompt exact?内层模型最大能多大？缓存 prompt 是否精确？

GPT-2 Medium (355M) and Large (774M) ran with a full forward pass, every position attending to every earlier one: 1,024 of 1,024 tokens, logits within 1.6×10-8 and 1.2×10-10. GPT-2 XL (1.56B, a 792,931-position prompt) needs a day that way, so we cached the prompt: its positions are never updated, so their keys and values are computed once per layer. On GPT-2 both passes ran: the same 1,024 tokens, logits within 4.6×10-14 of each other. In every cached run the sampled prompt positions received an update of exactly zero. GPT-2 XL then matched all 1,024 tokens at 3.1×10-10.

GPT-2 Medium（3.55 亿）和 Large（7.74 亿）用完整前向运行，每个位置注意所有之前的位置：1,024 / 1,024，logits 误差分别为 1.6×10-8 和 1.2×10-10。GPT-2 XL（15.6 亿，prompt 79 万个位置）这样要跑一天，所以我们缓存了 prompt：这些位置从不更新，它们的 key 和 value 每层只算一次。在 GPT-2 上两种方式都跑了：同样的 1,024 个 token，logits 相差 4.6×10-14。每次缓存运行中，抽查的 prompt 位置收到的更新都恰好是零。GPT-2 XL 随后 1,024 个 token 全部一致，误差 3.1×10-10。

Question 6问题 6

Answered已回答Can one outer network run models of every size?一个外层网络能运行所有尺寸的模型吗？

Yes, within a family. We wrote the outer network once, for GPT-2 XL's shape, and padded every smaller model with zeros: missing layers, heads, neurons, tokens and positions are zero; a narrower model's written vectors are centred, so that LayerNorm over the wider stream equals its own; head width and epsilon are read from the prompt. Six models ran on the same weights.

可以，在同一家族内。外层网络只按 GPT-2 XL 的形状写一次，更小的模型都用零补齐：缺的层、头、神经元、token 和位置都是零；较窄模型写入的向量先去均值，使更宽残差上的 LayerNorm 等于它自己的 LayerNorm；头宽和 epsilon 从 prompt 读入。六个模型在同一套权重上运行。

Question 7问题 7

Answered已回答Can a GPT-2-family network run the Llama family, with an exact SiLU?GPT-2 家族的网络能运行 Llama 家族吗？SiLU 能精确吗？

Yes. The outer network stays a GPT-2-family transformer. RMSNorm is its LayerNorm on a mean-zero stream. Products come from the even part of GELU, gelu(s) + gelu(−s) ≈ 0.80 s2, at three scales. Rotary positions are a looked-up cos/sin row and two products per coordinate. SiLU is exact: tanh-GELU is gelu(w) = w·σ(φ(w)), so silu(z) = 2k·gelu(w)(1 + cw2) for φ(w) = z, and w comes from a piecewise-linear guess and Newton steps. Random Llama-family models of several shapes run to 10−11; TinyLlama-1.1B to 1.4×10-9, SmolLM2-135M to 5.1×10-7 (question 8 explains both).

可以。外层仍然是 GPT-2 家族的 transformer。RMSNorm 就是它在均值为零的残差上的 LayerNorm。乘法取自 GELU 的偶部 gelu(s) + gelu(−s) ≈ 0.80 s2，用三个尺度。旋转位置编码是查出的一行 cos/sin 加上每个坐标两次乘法。SiLU 是精确的：tanh 版 GELU 满足 gelu(w) = w·σ(φ(w))，所以当 φ(w) = z 时 silu(z) = 2k·gelu(w)(1 + cw2)，w 由分段线性初值和牛顿迭代得到。各种形状的随机 Llama 家族模型都到 10−11；TinyLlama-1.1B 到 1.4×10-9，SmolLM2-135M 到 5.1×10-7（问题 8 解释这两个数）。

Question 8问题 8

Answered已回答Why did TinyLlama lose seven digits, and what restored them?TinyLlama 为什么丢了七位精度？怎么找回来的？

The first TinyLlama run matched every token but its logits were off by 10−2, seven digits worse than GPT-2. Per-layer comparisons found two causes. Without the beginning-of-text token, the down projection of layer 0 reached 102 times its calibrated maximum at the first position, where a massive activation forms, and the linearized product broke there; a smaller step (10−3) and calibration on four separate stories brought the error to 1.4×10-9. With the beginning-of-text token, the error stays: that token's residual vector has norm 10−11, RMSNorm multiplies it by 316, the model amplifies a perturbation there about twenty times per layer, and every position attends to it. The construction's errors are absolute, about 10−12 of the largest value, which is a relative error of 5×10−4 at that token. Calibrating on the test text itself made it worse, which ruled out calibration. SmolLM2's 5.1×10-7 has a third cause: values of 1.9×104 in its residual stream from layer 11 to 27, which its last layers cancel.

第一次运行 TinyLlama 时每个 token 都对上了，但 logits 误差是 10−2，比 GPT-2 差了七位。逐层比较找到了两个原因。不带开头 token 时，第 0 层的 down 投影在第一个位置（那里会形成超大激活）达到校准最大值的 102 倍，线性化的乘积在那里失效；把步长减小到 10−3 并在四段独立故事上校准后，误差降到 1.4×10-9。带开头 token 时误差仍在：这个 token 的残差范数只有 10−11，RMSNorm 把它放大 316 倍，模型在这里每层把扰动放大约二十倍，而所有位置都在注意它。构造的误差是绝对误差，约为最大值的 10−12，在这个 token 上就是 5×10−4 的相对误差。直接在测试文本上校准反而更差，排除了校准的原因。SmolLM2 的 5.1×10-7 是第三个原因：它的残差在第 11 到 27 层带着 1.9×104 的数值，最后几层再抵消掉。

Question 9问题 9

Testing进行中Does one outer network run many Llama-family models?一个外层网络能运行多个 Llama 家族模型吗？

One outer network written for the largest shape among TinyLlama-1.1B, Qwen2.5-0.5B, SmolLM2-360M and SmolLM2-135M, with every model padded with zeros (width, layers, heads, head width, key/value groups, vocabulary). On random models of four shapes it runs to 2×10−11. The run on the four checkpoints is waiting for a GB200 node.

按 TinyLlama-1.1B、Qwen2.5-0.5B、SmolLM2-360M 和 SmolLM2-135M 中最大的形状写一个外层网络，每个模型都用零补齐（宽度、层数、头数、头宽、kv 分组、词表）。在四种形状的随机模型上误差为 2×10−11。四个真实检查点的运行正在等 GB200 节点。

Question 10问题 10

Answered已回答Does the construction need float64?这个构造必须用 float64 吗？

Yes. The construction spends digits in cancellations: a pair ±1012 that makes LayerNorm linear, the even part of GELU at small scales, and products read out of tiny deviations of softmax weights. Float64 leaves about eleven of its sixteen digits; float32 leaves two to five of its seven.

需要。构造在几处相消里要用掉不少位数：让 LayerNorm 变成线性的 ±1012 这对数、小尺度下 GELU 的偶部、从 softmax 权重的微小偏差里读出乘积。float64 的 16 位里还能剩下约 11 位；float32 的 7 位里只剩 2 到 5 位。

Takeaways结论

  • A fixed GPT-2-family transformer can run another transformer that is only data in its prompt, at every position and to 9–11 digits, from 7K to 1.56B parameters. Ordinary float32 inference reaches 3–4 digits on the same checks.一个固定的 GPT-2 家族 transformer 能运行只作为 prompt 数据出现的另一个 transformer，每个位置都对，精度 9 到 11 位，规模从 7 千到 15.6 亿参数。普通 float32 推理在同样的检查上只有 3 到 4 位。
  • The parts of another architecture can be built from GPT-2's: RMSNorm, rotary positions and an exact SiLU, enough to run TinyLlama-1.1B to 1.4×10−9.另一种架构的部件可以用 GPT-2 的部件搭出来：RMSNorm、旋转位置编码和精确的 SiLU，足以把 TinyLlama-1.1B 运行到 1.4×10−9。
  • The construction's error is absolute, so it fails exactly where a model is sensitive to a tiny value. That is the one result here that a different construction would have to fix.构造的误差是绝对误差，所以它恰好在模型对极小数值敏感的地方失效。这是这里唯一需要换一种构造才能解决的结果。
  • Every number that looked like a precision limit turned out to be a bug or a range problem, found by comparing intermediate values layer by layer.每一个看起来像精度极限的数字，最后都被证明是 bug 或范围问题，都是通过逐层比较中间值找到的。
