LLM in LLM

A transformer whose prompt is another transformer. None of its weights were trained: Claude wrote the program that sets every one of them. Give it the weights of GPT-2 XL or TinyLlama-1.1B and it runs those models, matching every next token.

一个 prompt 是另一个 transformer 的 transformer。它的权重一个都没有训练过：每一个都由 Claude 写的程序直接设定。把 GPT-2 XL 或 TinyLlama-1.1B 的权重交给它，它就运行这些模型，每一个下一个 token 都对得上。

Xingyu Dang党星宇 · experiment log实验日志

TL;DR

We built an ordinary GPT-2-style transformer (softmax attention, LayerNorm, GELU) that never saw a gradient. Its prompt is another language model: each row of each weight matrix of, say, GPT-2 XL takes one position, 792,931 positions in all, and the tokens of a text come after. At every token, its output is the next token that GPT-2 XL predicts. The weights of the outer network (290 layers, width 24,569) are set by about 600 lines of Python that Claude wrote.

我们造了一个普通的 GPT-2 式 transformer（softmax 注意力、LayerNorm、GELU），它从没经过一步梯度更新。它的 prompt 是另一个语言模型：比如 GPT-2 XL 的每个权重矩阵的每一行占一个位置，一共 792,931 个位置，后面跟着一段文本的 token。在每个 token 上，它输出的就是 GPT-2 XL 预测的下一个 token。外层网络（290 层，宽 24,569）的权重由 Claude 写的约 600 行 Python 设定。

One set of these weights runs six models, from a 0.7M-parameter character model to the 1.56B-parameter GPT-2 XL. For each, all 1,024 next tokens match, and the logits agree with a float64 run of the model to 9 to 11 digits; ordinary float32 inference agrees to about 3 or 4. A second construction runs the Llama family on the same GPT-2 parts: TinyLlama-1.1B inside a GPT-2-architecture transformer matches all 1,024 next tokens, with logits within 1.4×10-9. RMSNorm, rotary positions and SwiGLU, including an exact SiLU, are built from LayerNorm, softmax and GELU. The outer network is itself a transformer, so it can be a prompt too: we ran a TinyStories model inside a transformer inside another transformer.

同一套权重跑了六个模型，从 70 万参数的字符模型到 15.6 亿参数的 GPT-2 XL。每个模型的 1,024 个下一个 token 全部一致，logits 与该模型 float64 运行的结果对上 9 到 11 位；普通 float32 推理只对上 3 到 4 位。第二个构造用同样的 GPT-2 零件运行 Llama 家族：GPT-2 架构的 transformer 里跑 TinyLlama-1.1B，1,024 个下一个 token 全部一致，logits 误差 1.4×10-9。RMSNorm、旋转位置编码和 SwiGLU（包括精确的 SiLU）都由 LayerNorm、softmax 和 GELU 搭出来。外层网络本身也是 transformer，所以它也能被放进 prompt：我们让一个 TinyStories 模型在一个 transformer 里运行，而这个 transformer 又在另一个 transformer 里运行。

What the outer transformer reads外层 transformer 读的是什么

Nothing about the inner model is in the outer model's weights. Those depend only on the inner model's shape (width, layers, heads, vocabulary). The inner weights arrive as data. Figure 2 draws the input for GPT-2 XL to scale: the text is the last 0.13% of it.

外层模型的权重里没有任何关于内层模型的信息，它们只取决于内层模型的形状（宽度、层数、头数、词表）。内层权重是作为数据进来的。图 2 按比例画出了 GPT-2 XL 对应的输入：文本只占最后 0.13%。

Each operation of the inner model is carried out by parts the outer model already has. The table lists them. The two that need a trick are the matrix products, since the matrix sits in the prompt and not in the outer weights, and the normalizations.

内层模型的每一种运算都由外层已有的部件来完成，下表列出了对应关系。需要技巧的是两类：矩阵乘法（因为矩阵在 prompt 里，不在外层权重里）和归一化。

One outer network for six GPT-2-family models一个外层网络运行六个 GPT-2 家族模型

We wrote the outer transformer once, for the shape of GPT-2 XL, and changed nothing for the other models. A smaller model is padded with zeros: missing layers, heads and neurons are zero, and its residual vectors are centred so that LayerNorm over the wider stream gives the same result. Each model then reads the first 1,024 tokens of Alice in Wonderland, and we compare the outer network's output with the model run directly in float64.

外层 transformer 只按 GPT-2 XL 的形状写了一次，换模型时不做任何改动。更小的模型用零补齐：缺的层、头、神经元都是零，残差向量先去均值，使更宽的残差上的 LayerNorm 给出同样的结果。每个模型读入《爱丽丝漫游奇境》的前 1,024 个 token，我们把外层网络的输出和该模型在 float64 下直接运行的结果相比较。

With the prompt cached (the prompt positions never change, so their keys and values are computed once per layer, as a key-value cache would), one model takes 14 minutes on one B200. Without the cache, GPT-2 small took 7 minutes on four B200s and gave the same tokens, with logits within 5×10−14 of the cached pass.

缓存 prompt 时（prompt 位置的值从不改变，所以它们的 key 和 value 每层只算一次，就像 KV cache），一个模型在一张 B200 上需要 14 分钟。不缓存时，GPT-2 small 在四张 B200 上用了 7 分钟，给出同样的 token，logits 与缓存版本相差不到 5×10−14。

A GPT-2 that runs Llama一个运行 Llama 的 GPT-2

The Llama family uses parts GPT-2 does not have: RMSNorm, rotary position embeddings, grouped-query attention and the SwiGLU MLP, whose gate is SiLU. A second construction keeps the outer network a GPT-2-family transformer and builds each of them from LayerNorm, softmax and GELU.

Llama 家族用到了 GPT-2 没有的部件：RMSNorm、旋转位置编码（RoPE）、分组查询注意力（GQA），以及门控为 SiLU 的 SwiGLU MLP。第二个构造让外层仍然是 GPT-2 家族的 transformer，用 LayerNorm、softmax 和 GELU 把这些部件一一搭出来。

  • RMSNorm. The outer residual stream has mean zero by construction, so the outer LayerNorm, which subtracts the mean, is an RMSNorm.RMSNorm。外层残差的均值按构造恒为零，所以减均值的外层 LayerNorm 就是 RMSNorm。
  • Products. gelu(s) + gelu(−s) = s·tanh(…) ≈ 0.80 s2 for small s. Three scales cancel the s4 and s6 terms, and xy = ((x+y)2 − (x−y)2)/4. Relative error about 10−13.乘法。当 s 很小时，gelu(s) + gelu(−s) = s·tanh(…) ≈ 0.80 s2。用三个尺度消去 s4 和 s6 项，再用 xy = ((x+y)2 − (x−y)2)/4。相对误差约 10−13。
  • Rotary positions. The cos and sin of a position are looked up from the prompt like an embedding; rotating q and k is two products per coordinate.旋转位置编码。每个位置的 cos 和 sin 像嵌入一样从 prompt 里查出来；旋转 q 和 k 就是每个坐标两次乘法。
  • SiLU, exactly. The tanh form of GELU is gelu(w) = w·σ(φ(w)) with φ(w) = 2k(w + cw3). So silu(z) = z·σ(z) = 2k·gelu(w)·(1 + cw2) when φ(w) = z. The outer network finds w with a piecewise-linear first guess and Newton steps made of products (Figure 4).精确的 SiLU。tanh 版 GELU 满足 gelu(w) = w·σ(φ(w))，其中 φ(w) = 2k(w + cw3)。所以当 φ(w) = z 时，silu(z) = z·σ(z) = 2k·gelu(w)·(1 + cw2)。外层用分段线性的初值加上由乘法构成的牛顿迭代求出 w（图 4）。

TinyLlama-1.1B inside this GPT-2-family network: 552 outer layers, width 82,154, a prompt of 459,353 positions. All 1,024 next tokens match, the logits are within 1.4×10-9 of the model run in float64 (float32 inference: 6.0×10-4), and one pass takes 4 minutes on one B200.

在这个 GPT-2 家族的网络里运行 TinyLlama-1.1B：外层 552 层，宽 82,154，prompt 有 459,353 个位置。1,024 个下一个 token 全部一致，logits 与模型 float64 运行结果相差不到 1.4×10-9（float32 推理：6.0×10-4），一次前向在一张 B200 上用 4 分钟。

SmolLM2-135M, also of the Llama family, on a network written for its own shape, matches all 1,024 next tokens with logits within 5.1×10-7. That is fewer digits than the other models because its residual stream carries values of 1.9×104 from layer 11 to layer 27 that its last layers cancel; the construction's absolute errors, about 10−12 of those values, are what remains.

同属 Llama 家族的 SmolLM2-135M，在按它自己形状写的网络上，也是 1,024 个下一个 token 全部一致，logits 误差 5.1×10-7。位数比其他模型少，是因为它的残差在第 11 到 27 层带着 1.9×104 量级的数值，最后几层再把它们抵消掉；构造的绝对误差约为这些数值的 10−12，抵消之后留了下来。

The same padding as before gives one outer network for the family. Written for the largest shape among four models (32 layers, width 2,048, vocabulary 151,936), it has 802 layers, width 84,042 and a prompt of 993,153 positions. TinyLlama-1.1B, Qwen2.5-0.5B, SmolLM2-360M and SmolLM2-135M each match all 1,024 next tokens on those weights, at about 23 minutes per model; their logit errors are 9.3×10-10, 7.0×10-8, 3.6×10-6, 1.8×10-5. These are the Llama-family bars of Figure 3. SmolLM2-135M loses about a digit and a half against the network written for its own shape, and we have not traced where yet.

用和前面一样的补零，就得到这个家族共用的一个外层网络。它按四个模型中最大的形状来写（32 层、宽 2,048、词表 151,936），有 802 层、宽 84,042，prompt 为 993,153 个位置。TinyLlama-1.1B、Qwen2.5-0.5B、SmolLM2-360M 和 SmolLM2-135M 在这套权重上各自的 1,024 个下一个 token 全部一致，每个模型约 23 分钟；logits 误差依次为 9.3×10-10、7.0×10-8、3.6×10-6、1.8×10-5。图 3 里 Llama 家族的条就是这些数。SmolLM2-135M 比按它自己形状写的网络少了大约一位半，原因还没有查清。

The outer network writes text, one token at a time外层网络自己逐个 token 写出文本

Everything above compares one forward pass over a given text. The outer network also generates. After a short start, the token it outputs at the last position is fed back as its next input token, and the loop uses nothing of the inner model. Its output head gives the most likely token, so this is greedy decoding. For every model below, the tokens it writes are the same as those of the model run directly in float64 with greedy decoding.

上面的结果比较的都是一段给定文本上的一次前向。外层网络也能自己生成：给一小段开头之后，它在最后一个位置输出的 token 被喂回去作为下一个输入 token，这个循环里不使用内层模型的任何东西。它的输出头给出的是概率最高的 token，所以这是贪心解码。下面每个模型，它写出的 token 都和该模型在 float64 下直接贪心解码的结果相同。

The interpreter picture is clearest when only the model changes. We wrote one outer network for the largest shape among Qwen2.5-0.5B, SmolLM2-360M and SmolLM2-135M (802 layers, width 68,610; a checksum of its weights is the same in all three runs), gave it the same start, and changed only the weights in its input. It continues the start as each model does, 24 of 24 tokens every time:

只换模型、别的都不变时，“解释器”这个说法最清楚。我们按 Qwen2.5-0.5B、SmolLM2-360M 和 SmolLM2-135M 中最大的形状写了一个外层网络（802 层，宽 68,610；三次运行里它的权重校验码相同），给它同一句开头，只更换输入里的权重。它每次都按那个模型的方式把这句话接下去，每次都是 24 / 24 个 token 一致：

The model is an input, so changing the model is changing the input模型是输入，所以改模型就是改输入

Five experiments on that one consequence. In each, something that is normally done to a model's weights is done to prompt positions instead, and the interpreter's output is compared with the same change made to the model itself.

围绕这一个推论做了五个实验。每个实验里，通常对模型权重做的事改成对 prompt 位置做，再把解释器的输出与直接对模型做同样改动的结果相比较。

Can the model in the prompt be trained by backpropagating through the interpreter?能不能把梯度穿过解释器反传回去，训练 prompt 里的模型？

Yes. The interpreter stays frozen. The loss is its own next-character loss; backpropagation runs through its 14 layers into its input, and the gradient that arrives at the prompt positions, divided by each row's scale, is the gradient of the inner model's weights. At random initial weights it agrees with the model's own gradient to a relative error of 1.3×10-10. We then trained the same 8,768-parameter character model twice, from the same start and on the same batches: once using only gradients that came through the interpreter, once directly. After 300 steps the held-out losses differ by at most 3.6×10-12, and the two models write the same text.

可以。解释器保持冻结。loss 就是它自己的下一个字符的 loss；反向传播穿过它的 14 层一直到输入，到达 prompt 位置的梯度除以每一行的尺度，就是内层模型权重的梯度。在随机初始权重处，它与模型自己的梯度相对误差为 1.3×10-10。然后我们把同一个 8,768 参数的字符模型从同一个起点、用同样的 batch 训练了两次：一次只用穿过解释器得到的梯度，一次直接训练。300 步之后，两者的留出 loss 最多相差 3.6×10-12，写出的文字也相同。

Is fine-tuning just a change of the prompt?微调是不是只是改一下 prompt？

Yes: any change of the weights is a change of prompt positions. We put base + α · (Instruct − base) of Qwen2.5-0.5B in the prompt and asked a question in the chat format. At α = 0 the interpreter answers as the base model does; from α = 0.25 on, as the instruction-tuned one does. In every case it writes, token for token, what the mixed model writes when run directly.

是的：对权重的任何改动都是对 prompt 位置的改动。我们把 Qwen2.5-0.5B 的 基础版 + α ·（指令版 − 基础版）放进 prompt，用对话格式提一个问题。α = 0 时解释器像基础版那样回答；从 α = 0.25 起就像指令微调版那样回答。每一种情况下，它写出的 token 都与直接运行这个混合模型逐个一致。

Can one fact be changed by editing a few prompt positions?能不能只改几个 prompt 位置就改掉一个事实？

GPT-2 continues “The Eiffel Tower is located in the city of” with “Paris”. 8 steps of gradient descent on one matrix of the model (the MLP output matrix of layer 5, changed by 1.4% in norm) make it say “Rome”. In the prompt that is 768 of 184,531 positions; nothing else differs, and the interpreter writes what the edited model writes. This is a plain gradient edit, so other facts may have moved with it; the point here is only where the edit lives.

GPT-2 会把“The Eiffel Tower is located in the city of”接成“Paris”。对模型的一个矩阵（第 5 层 MLP 的输出矩阵，范数改变 1.4%）做 8 步梯度下降，它就改口说“Rome”。在 prompt 里这只是 184,531 个位置中的 768 个，其余完全不变，解释器写出的就是改后模型写出的内容。这是最朴素的梯度编辑，别的事实可能也被带动了；这里要说明的只是这次编辑落在哪里。

Can interpretability experiments be run by editing the prompt?能不能通过改 prompt 来做可解释性实验？

Switching off an attention head is setting its 64 value rows in the prompt to zero; removing a layer is setting the 1,536 rows of its two output matrices to zero. On an indirect-object task (8 prompts such as “When Mary and John went to the store, John gave a drink to”) we measured the logit of the right name minus that of the wrong one under 14 such edits of GPT-2. The interpreter's logits equal those of the edited model run directly (largest difference 3.8×10-7). What the measurements say: zeroing the three name-mover heads of Wang et al. (2022) leaves the difference almost unchanged (3.07 to 3.13; that paper describes backup heads that take over), removing layer 0 destroys it (-0.36), and removing the last layer doubles it (6.47).

关掉一个注意力头，就是把它在 prompt 里的 64 行 value 置零；去掉一层，就是把它两个输出矩阵的 1,536 行置零。在间接宾语任务上（8 条形如 “When Mary and John went to the store, John gave a drink to” 的 prompt），我们对 GPT-2 做了 14 种这样的编辑，测量正确名字与错误名字的 logit 之差。解释器的 logits 与直接运行编辑后模型的结果一致（最大差 3.8×10-7）。测量结果本身：把 Wang 等（2022）的三个 name mover 头置零，差值几乎不变（3.07 到 3.13；该论文描述了会接替它们的 backup 头）；去掉第 0 层会毁掉这个差值（-0.36）；去掉最后一层则使它翻倍（6.47）。

Is the interpreter an ordinary transformer? Load it with stock transformers.解释器是不是一个普通的 transformer？用原版 transformers 加载它。

We exported the interpreter as a transformers.GPT2LMHeadModel (26 layers, width 1,560, 6 heads; 331M parameters, stored densely in float64) and loaded it back with from_pretrained. No custom code is involved: the other model's weights go in as inputs_embeds, and the text uses the checkpoint's own token embeddings. Its logits equal those of the 217,728-parameter character model in the prompt to 7.2×10-12, and generate writes that model's text: “Once upon a time, there was a little girl named Lily. She loved to play with her toys and her fri…”. Sampling agrees too: with the same random numbers at every step, 91 of 91 sampled characters are equal. The models here are small because the interpreter for GPT-2, stored densely, would take terabytes (almost all of it zeros); the construction is the same one.

我们把解释器导出成一个 transformers.GPT2LMHeadModel（26 层、宽 1,560、6 个头；331M 参数，以 float64 稠密存储），再用 from_pretrained 加载回来。不需要任何自定义代码：另一个模型的权重作为 inputs_embeds 输入，文本用的是检查点自己的词嵌入。它的 logits 与 prompt 里那个 217,728 参数的字符模型相差 7.2×10-12，generate 写出的就是那个模型的文字：“Once upon a time, there was a little girl named Lily. She loved to play with her toys and her fri…”。采样也一致：每一步使用同样的随机数时，91 个采样字符中有 91 个相同。这里的模型很小，是因为 GPT-2 对应的解释器如果稠密存储要占几个 TB（几乎全是零）；构造是同一个。

A transformer inside a transformer inside a transformertransformer 里的 transformer 里的 transformer

The outer network is a GPT-2-family transformer, so it can be the prompt of another outer network, written for its shape. Two details make that work: every vector the network writes sums to zero, so its own LayerNorm can be treated as an RMSNorm one level up; and every flag that a mask reads is multiplied by a power of two, so the masks cancel exactly. We trained a character model on TinyStories and ran it two levels deep.

外层网络本身是 GPT-2 家族的 transformer，所以它可以成为另一个外层网络的 prompt，后者按它的形状来写。能做到这一点靠两处细节：网络写入的每个向量之和为零，所以它自己的 LayerNorm 在上一层看来可以当作 RMSNorm；每个被 mask 读取的标记都乘以 2 的幂，所以 mask 的抵消是精确的。我们在 TinyStories 上训练了一个字符模型，让它在两层套娃里运行。

Where it falls short做不到的地方

The construction's errors are absolute: about 10−12 of the largest value a quantity takes at any position. That is fine wherever values have their usual size, and it fails where the model is extremely sensitive to a value that is tiny. TinyLlama's beginning-of-text token is such a place. Its residual vector has norm 10−11 in the first layers, so RMSNorm, dominated by its epsilon, multiplies it by 316; the model amplifies a perturbation there about 20 times per layer, and every position attends to that token. With it, the logit error is 10−2 (float32 inference: 3×10−4); the next tokens still all match. Without it, the error stays at 10−11 through every layer (Figure 7).

构造的误差是绝对误差：约为某个量在所有位置上最大值的 10−12。数值在正常量级时这没问题；但如果模型对一个极小的数值极其敏感，就会出问题。TinyLlama 的开头 token（BOS）正是这样：它的残差向量在前几层范数只有 10−11，RMSNorm 被 epsilon 主导，等于把它放大 316 倍；模型在这里每层把扰动放大约 20 倍，而所有位置都在注意这个 token。带上它时 logits 误差是 10−2（float32 推理：3×10−4），下一个 token 仍然全部一致；去掉它，误差在每一层都保持在 10−11（图 7）。

  • Float64 is needed. The construction spends several digits in cancellations. Evaluated in float32, the same weights reach 3×10−6 (GPT-2 family) and 10−4 (Llama family) on small random models.需要 float64。构造在几处相消里要用掉好几位有效数字。同样的权重用 float32 计算时，在小的随机模型上只能到 3×10−6（GPT-2 家族）和 10−4（Llama 家族）。
  • Greedy output for large vocabularies. When the vocabulary is wider than the outer network, its last head points at the inner model's top token instead of reproducing all logits. The comparisons above read the logits from the inner residual stream the outer network carries.大词表只输出最可能的 token。词表比外层网络还宽时，外层最后一个头指向内层模型概率最高的 token，而不是复现全部 logits。上面的比较是从外层携带的内层残差上读出 logits 的。
  • Greedy decoding only. When it generates, the outer network can only take the most likely token; sampling would need the full distribution at the output.只能贪心解码。生成时外层网络只能取概率最高的 token；要采样就需要在输出端给出完整的分布。
  • A calibration pass. The loader scales each matrix row by its largest value on four short TinyStories texts, much like the calibration step of quantization.一次校准。加载器按每个矩阵行在四段 TinyStories 短文上的最大值给它定尺度，类似量化里的校准步骤。
  • Big, mostly empty weights. Counted densely, the outer network for GPT-2 Large has 1.9 trillion parameters; 590 million are nonzero.权重很大，但大多是零。按稠密计算，GPT-2 Large 对应的外层网络有 1.9 万亿参数，其中非零的只有 5.9 亿。
  • Families covered. GPT-2 (LayerNorm, learned positions, tanh-GELU) and Llama (RMSNorm, rotary, GQA, SwiGLU; Qwen2's biases too). Not yet: exact erf-GELU, per-head q/k normalization (Qwen3), mixture-of-experts routing, sliding-window attention.支持的家族。GPT-2（LayerNorm、学习的位置嵌入、tanh 版 GELU）和 Llama（RMSNorm、RoPE、GQA、SwiGLU；也支持 Qwen2 的偏置）。还不支持：精确的 erf 版 GELU、按头的 q/k 归一化（Qwen3）、MoE 路由、滑动窗口注意力。

How it was built是怎么做出来的

Claude wrote the construction in a single working session over three days: Fable 5.2 wrote the GPT-2-family interpreter, the padding and the three-level tower; Opus 5.5 the Llama-family construction. No weight of the outer network was trained. Xingyu set the goals (a real model rather than a toy, then one interpreter for every size, then Llama with an exact SiLU) and asked questions; Claude designed the construction, wrote the code, ran the experiments on GPUs and found its own bugs by comparing the outer network's intermediate values with the inner model's, layer by layer.

构造是 Claude 在一个连续的工作会话里用三天写出来的：Fable 5.2 写了 GPT-2 家族的解释器、补零和三层套娃；Opus 5.5 写了 Llama 家族的构造。外层网络没有任何一个权重经过训练。星宇定目标（先是要跑真实模型而不是玩具，然后是一个解释器跑所有尺寸，再然后是用精确 SiLU 跑 Llama）并提问；Claude 设计构造、写代码、在 GPU 上跑实验，并且通过逐层比对外层网络的中间值和内层模型的值来自己找 bug。

Three of those bugs are worth telling, because each one looked like a precision limit and was not. An offset was added to the same weight row as a mask of size 1024 and disappeared in the sum, which broke a width-64 tower until it moved to its own row. A clearing step ran in a layer where the outer LayerNorm was not linear and wrote 10−8 of garbage instead of zero. And the first token of a TinyLlama text forms a massive activation 101 times larger than anything in the calibration text, which a smaller linearization step absorbed.

其中三个 bug 值得一提，因为它们看起来都像精度极限，实际上都不是。一个偏移量和一个 1024 的 mask 加在同一行权重上，在求和中被吃掉了，导致宽 64 的套娃失败，直到把它挪到单独一行。一个清零步骤被放在了外层 LayerNorm 不是线性的层里，结果写进了 10−8 的垃圾而不是零。还有，TinyLlama 文本的第一个 token 会形成超大激活，比校准文本里的任何值都大 101 倍，用更小的线性化步长才把它吸收掉。
